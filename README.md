# Atividades de Estrutura de Dados

- **atividade-01**: tabela com 100 posições, 1000 inserções aleatórias (seed 1090) e lista encadeada nas colisões.
- **atividade-02**: tabela com endereçamento aberto (sondagem linear), 100 tentativas de inserção e bloqueio ao chegar em 90% de ocupação.

Compilar e rodar:

```
javac atividade-01/TabelaHash.java
java -cp atividade-01 TabelaHash
```
